# The Architect — 20-Agent Doctrinal Source Method

## Primary evidence and origin

- **Book I:** `THE HYBRID SOVEREIGN Peace Doctrine - The Book.docx` / The Hybrid Sovereign (document ID `A`).
- **Book II:** `The Architect World Peace Doctrine and Strategy FINAL With_Index.docx` / HSPD (document ID `B`).
- **Post-publication addendum:** `HSPD_Adversarial_Validation_Errata_Addendum_v1.1(1).docx` (document ID `C`).
- **October 2026 functional agent roster:** The Architect project conversation. The twenty role slots predate this software library; the heroic proper names are post-manuscript creative design decisions, not book quotations.

## Source representation

A single `arbiter/knowledge.js` preserves 7,087 source passages with immutable-looking passage IDs, book IDs, chapter IDs, section names and verbatim text from the uploaded files. `agents/AGENT_PROFILES.json` includes an individually bounded mission, input/output schema, eight candidate capacities, falsification tests, and source passage identifiers for each of twenty profiles. Source passage IDs can be looked up in the shared library and displayed in the browser. Machine-picked passages **are candidates**; they do not prove the proposed capability is entailed by that passage.

## Distinctions that matter

1. **Book claim** — the author's passage, which may express a hypothesis, critique or desired architecture.
2. **Later addendum** — proposed revised safeguards; not identical to original published book.
3. **Engineer proposal** — synthesized agent role, method, software output contract and test. Do not cite as verbatim doctrine.
4. **Synthetic demo** — controlled test fixture; not real-world evidence or independent multi-model verification.
5. **Demonstrated capability** — would require implementation and blinded, replicated external testing. No such general validation is claimed.

## Critical boundaries

Book I Chapter 1 §13.8 explicitly prohibits the framework from becoming the final arbiter of truth, justice or ideology: its role ends at continuity. The Arbiter is therefore treated as an **evidence-integrity review process**, not ideological authority or autonomous coercive enforcement. Civilian life-preservation, protected dissent, causal falsifiability, provenance independence, documentation and review are retained from the addendum. All 20 agent-specific authority limits are proposed implementation constraints intended to safeguard these principles.

## Known gaps

- All 160 skills remain engineering proposals with candidate lexical source matches requiring detailed author review. A passage containing a keyword is **not** proof of the entire skill.
- Some analytical roles (for example, the two blind independent witnesses) arise most directly from the **post-publication** addendum rather than the older books. This difference is made explicit.
- No separate database was trained per agent. Roles share one source corpus but have different retrieved references and proposed instructions.
- Source excerpts in the profile are selected passages; use the full corpus search to verify broader chapter context.
- No source authenticated real-world observations, real agent instances, validated results or permission to operate actual infrastructure.
- The `HSPD Arena 0.1` group of **ten simulated role labels inside one language model** is historically distinct from this twenty-agent proposed roster.

## Suggested next review

Work agent by agent: inspect the exact quotations; classify each match as `direct`, `inferred`, `in tension` or `unsupported`; approve or remove the skill; refine each adversarial test and objective failure measure before using any profile as a prompt for a deployed agent.
