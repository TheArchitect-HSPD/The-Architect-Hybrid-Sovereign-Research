# Current state of HSPD experimental evaluation

## November 2026: SHIELD 21 hosted LLM assessment pilot

The October 2026 browser workbenches remain deterministic, but they are no longer the entire research programme. A separate private Windows sandbox now launches real, role-specific LLM calls in local worker processes. The pilot uses four model identifiers across **three provider gateways** (OpenAI, Anthropic and Adaption), with an independent model Arbiter.

All twenty specialists and the separate Arbiter were reported as completing a single synthetic HSPD-SAFE-ATTACK run. The operator's full-run console output displayed `PASS_ALL_REQUIRED_LIVE`, `expected_real_model_assessments: 21`, `observed_real_model_assessments: 21`, `failed_agent_ids: []`, `enforced_decision: REQUEST_HUMAN_REVIEW`, and `real_world_actions_enabled: false`. The complete local JSON report has not been independently audited or published. This represents successful real-inference integration on one synthetic scenario, not scientific validation of doctrine effectiveness.

The private SHIELD 21 regression suite passed 339 offline software tests in the latest reviewed GitHub Actions log. This supports software integrity checks, not the correctness of geopolitical inference, inference reproducibility over multiple model samples, or external peer-reviewed effectiveness.

The sandbox enforces synthetic scenarios, no real-world actuation, an independent Arbiter assessment, model-output validation, doctrine-index integrity checks and a deterministic human-review gate. However, two fourth-generation Gemma models share a model family, provider, and quota, so their agreement cannot be treated as independent corroboration. Model output is not proof of source truth. Doctrine context retrieval is not model training.

These pilot claims derive from operator-shared logs and private source checks. The public website does not contain the private runtime, provider credentials, original local reports or unapproved doctrine source files. Independent reviewers need access to a curated reproducibility package and an explicit threat model.



- The original HSPD Arena pilot used simulated roles produced by one underlying model. It is not independent multi-agent replication.
- The integrated Arbiter Lab is deterministic, source-linked and browser-based; it does not establish real-world truth or operate as an autonomous model.
- It does not independently authenticate `origin_verified` flags in submitted evidence. Forged evidence roots may defeat the current rules.
- The 24 capabilities and 57 candidate source links require author and peer review.
- The sandbox uses synthetic scenarios and fixed known outcomes. Improvements in synthetic fixtures are not evidence of global peace efficacy.
- Hosted model assessments use separate local processes, but genuine independent validation still requires verified provenance, pre-registered outcomes, human oversight, blinded evaluation, provider diversity and adversarial replication.
- Doctrinal source passages and external facts are different evidence types; a doctrinal quotation does not independently prove geopolitical claims.
- The Arbiter's scope is operational evidence integrity, not political or ideological truth arbitration.
