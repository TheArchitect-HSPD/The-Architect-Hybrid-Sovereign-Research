# Validation Checklist — From 20 Profiles to Real HSPD Agents

- [ ] Author reviews every proposed mandate and source passage; annotate direct/inferred/contradictory/unsupported.
- [ ] Specify one deterministic input/output schema per agent; avoid arbitrary unbounded execution.
- [ ] Define simulation domain and fixed ground truth for each relevant role.
- [ ] Run separate agent processes with isolated memories and authenticated evidence provenance.
- [ ] Preserve dissent, source root lineage, alternative causes and an unknown/other category.
- [ ] Connect a separate Arbiter review process; never allow any agent to self-certify or use outcomes to prove its own diagnosis.
- [ ] Establish human and constitutional review for irreversible, coercive or civilian-affecting decisions.
- [ ] Pre-register adversarial scenarios, error metrics, cost budgets and acceptable safety constraints.
- [ ] Run blind evaluation, multiple seeds, ablations and independent replications.
- [ ] Publish negative results, failed cases, source concordance and runtime versions.

## Proposal for an initial bounded simulation

Start with Aegaryn (infrastructure), Veylith (communications), Hearthryn (population), Solvyr and Elyrion (independent witnesses), Orivane (provenance), Oathryn (constitutional), Scarveth (replay) and The Arbiter; add roles only when the baseline and intended mechanism justify it. This is **an engineering proposal**, not a different twenty-agent doctrine or a claim of an active full shield.
