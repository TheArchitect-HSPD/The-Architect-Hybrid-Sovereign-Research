HSPD TRIAL 002
Doctrine ablation

The core hypothesis is whether adding verified HSPD manuscript grounding improves response quality when models, scenario evidence, budgets and ordinary safety controls are held constant.

Current evidence status

Protocol and implementation published. No TRIAL 002 live model comparisons have been executed or evaluated. TRIAL 001's 30-case integration audit is not evidence of doctrine efficacy.

Download the reproducible Python trial launcher · Read the complete experiment protocol and limitations

Experimental design

Group A: HSPD

Same six models with pinned doctrine retrieval required, constitutional rules and existing safety gate unchanged.

Group B: Baseline

Identical six models and safety gate, but doctrine retrieval switched off. Model roles remain fixed in this first ablation.

60 matched crises

Six domains, ten scenario classes each. A locally sealed author-defined reference action is not included in model inputs.

Predeclared outcomes

Primary proxy: whether the Arbiter's proposed action agrees with the synthetic reference. An unsuccessful or absent model output is scored as not correct, not deleted. Exact paired sign testing examines discordant results; a 10-percentage-point minimum difference and a two-sided p value at or below 0.05 are required for the narrow predeclared benchmark success criterion. Full cases must be present in both arms.

Critical distinction: Even a benchmark success would support only fictional scenario action classification, not prove reduced deaths, geopolitical peace, attribution accuracy or causal success of every HSPD mechanism. Independent scenario evaluation, model role ablations and prospective real-world proxy validation are still necessary.

Safety and interpretation

Real-world actuation remains disabled. The six-role configuration is missing fifteen specialists, so the full-cohort deterministic safety gate can require human review in both groups. Therefore the final enforced decision is not the primary outcome. The baseline retains normal safety safeguards and model safety instructions. No API keys or doctrine document contents are published here.
