# The Architect — HSPD Research Site (v0.2)

**Standalone GitHub Pages website.** Open `index.html` directly. All layout, scripts, names, functions and navigation are contained in one file: no CSS, JavaScript, font, or image dependencies.

## Installation

Replace your repository root `index.html` with the supplied version. GitHub Pages should remain configured to deploy from `main` / `/(root)`. The website appears at https://thearchitect-hspd.github.io/The-Architect-Hybrid-Sovereign-Research/ once Pages rebuilds.

## Provenance and safety

The twenty fantasy identities are **proposed**, not finalised author-approved legal names. Functional roles follow the HSPD project conversation and the author's adversarial addendum. Agent 21, **The Arbiter**, is author-named and sovereign as an epistemic oversight proposal. Neither the Arena 0.1 simulated roles nor the 30-case rule-based demonstration represents independent deployment or validation. Full unpublished manuscripts are not distributed.

## Architecture details

Twenty agent names and roles are visible in the HTML itself, and remain accessible without JavaScript. Filters and searching add convenience when JavaScript is enabled. All menu links are same-page anchors, so Pages deployment does not require additional HTML files.
