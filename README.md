# THE ARCHITECT — HSPD & THE ARBITER

A source-conscious research website for **Grigore Dincă (The Architect)**, author of the Hybrid Sovereign Peace Doctrine, and the proposed 21-agent architecture including **The Arbiter**.

**Read the publication checklist in [`docs/PUBLICATION_CHECKLIST.md`](docs/PUBLICATION_CHECKLIST.md) before making the site public.**

## What this site is

- An introduction to the HSPD conceptual framework.
- A source-concordant draft of the proposed 20 functional roles and the author-named Arbiter oversight identity.
- An evidence register separating source text, AI-assisted design, synthetic scenario testing and independently unverified results.
- A research invitation focused on reproducibility, adversarial evaluation and independent replication.

## What it is not

This is **not** evidence of a deployed 21-agent AI system, proven peace effectiveness, independently replicated agentic oversight, external institutional endorsement, or technically validated operational safeguards.

## Run locally

No build system, GitHub Actions, npm, API keys or external fonts are required. Open `index.html` in a browser. All paths are relative and work for project repositories hosted at `https://USERNAME.github.io/REPOSITORY/`.

Optional local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages (no coding required)

1. Sign in at [GitHub](https://github.com) and create a new repository, such as `hspd-the-arbiter`.
2. If on GitHub Free, choose **Public** to host through GitHub Pages. **Before selecting Public, read the publication checklist.**
3. On the new repository page choose **Add file → Upload files** and upload the **contents of this folder**, preserving the `assets`, `docs`, `research` and `.github` directories. **Do not upload the `.zip` instead of its contents.**
4. Commit the upload to the repository (usually branch `main`).
5. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
6. Set **Branch: `main`**, folder **`/(root)`**, then Save.
7. Open the Pages URL shown by GitHub after deployment: `https://YOUR-USERNAME.github.io/hspd-the-arbiter/` if using the suggested repo name.

GitHub documentation: [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [Configuring a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
