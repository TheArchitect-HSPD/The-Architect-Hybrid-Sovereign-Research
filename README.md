## November 2026 work

The experimental SHIELD 21 federation uses four specialist model pools of five worker roles each: OpenAI GPT 4.1 Mini, Anthropic Claude Haiku 5.5, Gemma 4 31B via Adaption, and Gemma 4 26B via Adaption. The Arbiter is separate and was evaluated with OpenAI GPT 6.1 Sol in the reported trials. Two of the models use the same family and inference gateway, so their outputs are not independent corroboration. Agents use local isolated processes with scoped doctrine retrieval, not separately trained weights.

An expanded pilot exposed real output-budget failures. Anthropic truncation was resolved with larger output ceilings for agents 06 and 10. DeepSeek V4 Flash used its entire reasoning-token allowance without final text on agents 08 and 12; Qwen 3.8 27B also returned an incomplete assessment. Gemma 4 26B then passed all five fourth-pool roles individually at a 4,096-token budget. The reported local offline suite passed 339 tests.

The 21/21 live outcome demonstrates that the software can complete the full model assessment pipeline on one synthetic scenario. It does not demonstrate inference accuracy, a validated prediction of geopolitical events, institutional endorsement, operational control, or achievement of the doctrine's peace KPIs.

## Six-role HSPD SHIELD 21 research update (11 November 2026)

A separate local pilot assigned five specialist roles and one Arbiter to six model IDs: OpenAI GPT 4.1 Mini, Anthropic Claude Haiku 5.5, Adaption Gemma 4 31B, Adaption Qwen 3.8 27B, Adaption Qwen 3.5 397B, and OpenAI GPT 6.1 Sol. This pilot does **not** supersede or repeat the previously reported 21-role coordinated cohort.

The operator reported 105/105 passing targeted regression tests and a successful six-role **mock** coordinator replay with no inference calls. In the live Delta72 V3 synthetic trial, five of six model receipts were valid, while Agent 05 exhausted its generation allocation. The structured BLACK MERIDIAN trial produced five successful specialist responses but an Arbiter output validation error. The plain-language BLACK MERIDIAN console trial produced four successful specialists plus a successful Arbiter; Agent 04 exhausted its 8,192-token output allowance, including 8,010 reported reasoning tokens. All three live trials were **incomplete at five of six**. Deterministic human review remained enforced, with no real-world control.

A local human research console can save and dispatch fictional text scenarios after explicit cloud consent, and a read-only viewer can display saved assessment receipts. These are **local prototype tools**, not interactive features of the public site. The narrative drafts are not independently authenticated or structurally validated evidence. The saved local reports remain unpublished and unaudited. See [the dated research update](shield21.html#november11).

## Public interactive laboratory (11 November 2026)

The [Interactive HSPD Lab](https://thearchitect-hspd.github.io/The-Architect-Hybrid-Sovereign-Research/lab.html) now runs six predefined evidence scenarios through three actual deterministic browser policies: raw majority, confidence weighting, and the independent-root Arbiter rule. Visitors can vary the shuffle seed, execute a 30-seed regression, inspect 21 labelled synthetic role traces, edit a custom fictional evidence scenario, export the browser trace, and open privately saved live federation JSON reports **locally in the browser**. This is fully functional offline policy simulation, not 21 separately running LLMs.

The GitHub Pages host is a static site. It cannot host the private Windows LLM processes, protect OpenAI/Anthropic/Adaption provider credentials, or provide secure multi-user inference by itself. A true live browser interface requires a separately hosted and authenticated backend, private doctrine storage, server-side usage limits, output validation, audit logs and an explicit operator consent flow. Do not place provider keys into public HTML or JavaScript. The live model control is therefore not presented as available on the website.

The repository restores `assets/app.js` and `assets/emblem.svg` for existing page navigation, and adds a GitHub Actions regression workflow checking JavaScript syntax, deterministic policy scenarios, basic internal links and lab control IDs. These checks are not browser end-to-end or external-link availability verification.

## Privacy and safety

The public website contains no API keys, local federation result JSON, private runtime configuration or new unpublished doctrine document uploads. The original October 2026 homepage already includes embedded doctrine passages, so repository publication settings and intellectual property implications require the author's review.

The LLM federation is restricted to explicitly synthetic scenarios, has no real-world actuation and enforces human review through a deterministic gate. The Arbiter is an epistemic reviewer, not an authority over political truth, public belief, justice or ideology.
